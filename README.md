# Wireless Battery Hub

Лёгкая утилита для Windows 10/11, которая показывает уровень заряда **беспроводных мышей, клавиатур, геймпадов и гарнитур** прямо в системном трее (возле значка громкости).

Работает без установки стороннего софта и драйверов, собирается в один автономный `WirelessBatteryHub.exe` через GitHub Actions.

---

## Возможности

- **Событийная работа (0% нагрузки в простое):** полное сканирование запускается только при старте программы, подключении/отключении USB или Bluetooth устройства (`WM_DEVICECHANGE`) и выходе ПК из сна. При желании можно включить редкое обновление раз в 2 минуты.
- **Только подключённые устройства в трее:** отключённые девайсы не захламляют панель задач.
- **Память сна для 2.4 ГГц:** если мышь уснула, а USB-донгл всё ещё вставлен в ПК, значок не пропадает и не сбрасывается на `--`, а показывает последний известный процент.
- **3 стиля значка в трее:**
  - *Бейдж* (тёмная карточка с полосой типа устройства и шкалой заряда);
  - *Крупные цифры* (без фона, с автоадаптацией под светлую и тёмную панель задач Windows);
  - *Батарейка* (иконка с цветным заполнением).
- **Цветовая метка типа устройства сверху на значке:**
  - Бирюзовая — **Мышь**
  - Фиолетовая — **Клавиатура**
  - Золотая — **Геймпад**
  - Малиновая — **Гарнитура**
- **Умные уведомления:** предупреждает о низком заряде (порог настраивается, по умолчанию ≤ 15%) и о полной зарядке (100%) без спама.
- **Гибкое управление списком:** по правому клику в таблице можно **переименовать** устройство или **скрыть** лишние (например, BT-колонку) из трея.
- **Прогноз времени работы:** оценивает оставшееся время автономной работы по реальному темпу разряда.
- **Тёмная и светлая тема окна**, автозапуск вместе с Windows (`--minimized`), сворачивание в трей и встроенная проверка обновлений.

## Установка и запуск

1. Скачайте готовый `WirelessBatteryHub.exe` со страницы **Releases** (или из последнего успешного запуска во вкладке **Actions → Artifacts**).
2. Поместите `WirelessBatteryHub.exe` в удобную папку (дополнительные библиотеки не требуются — `.NET 8` уже вшит внутрь).
3. Запустите программу.
4. **Совет для Windows 11:** новые значки сначала попадают в меню под стрелкой `^` возле часов — перетащите их мышкой прямо на панель задач к громкости.

> Повторный запуск `.exe`, когда программа уже работает в фоне, откроет главное окно поверх всех окон.

## Как добавить неизвестное 2.4 ГГц устройство

Если ваша мышь, клавиатура или гарнитура работает через нестандартный USB-донгл и не определилась автоматически:

1. Нажмите в окне кнопку **«HID-Анализатор»**.
2. Выберите Vendor-интерфейс вашего донгла из списка.
3. При необходимости укажите текущий известный процент заряда (из родного ПО).
4. Нажмите **«Слушать пакеты»** и пошевелите мышкой / нажмите клавишу — при совпадении программа подсветит нужный байт и разблокирует кнопку **«Сохранить в JSON»**.

Правила сохраняются в файл `protocols.json` рядом с программой и не требуют перекомпиляции.

## Сборка из исходников

Требуется [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) на Windows:

```powershell
dotnet publish src/WirelessBatteryHub.csproj `
  -c Release `
  -r win-x64 `
  --self-contained true `
  -p:PublishSingleFile=true `
  -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:EnableCompressionInSingleFile=true `
  -o publish
```

Либо просто создайте тег вида `v1.0.0` на GitHub — workflow `.github/workflows/build.yml` сам сгенерирует иконку, соберёт `.exe` и опубликует его в **Releases**.
